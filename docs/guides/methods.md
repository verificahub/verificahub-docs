# Методы подтверждения и тарифы

Verificahub поддерживает несколько способов подтвердить номер. Все они вызываются через один эндпоинт `POST /v1/verify` — меняется только значение поля `method`.

## Сравнение методов

| Метод | `method` | Как подтверждается | Цена за подтверждение |
| --- | --- | --- | --- |
| Обратный flash-call | `reverse_flash_call` | Пользователь сам звонит на наш номер, подтверждаем по Caller ID — кода нет | **0,25 ₽** |
| Flash Call | `flash_call` | Звонок-сброс на номер пользователя; код — последние цифры входящего номера | **0,80 ₽** |
| Telegram | `telegram` | Код приходит в Telegram через официального бота | **0,90 ₽** |
| MAX | `max_bot` | Код приходит в мессенджере MAX после того, как пользователь поделится номером в боте | *по тарифу аккаунта* |
| SMS | `sms` | Классический код в SMS — работает на любом телефоне | **3,00 ₽** |
| Voice OTP | `voice` | Голосовой робот диктует код | *скоро* |

Цены указаны ориентировочно; актуальные тарифы — на [verificahub.ru](https://verificahub.ru). Метод
`max_bot` доступен, если подключён для вашего аккаунта; его цену смотрите в личном кабинете или через `GET /v1/prices`.

## Два сценария интеграции

Методы делятся на два типа по тому, как происходит подтверждение.

### Автоматический — без ввода кода

Только `reverse_flash_call`. Вы показываете пользователю номер (`number_to_call`), он звонит, а вы опрашиваете статус сессии до `verified`.

→ [Обратный flash-call](./reverse_flash_call.md)

### С вводом кода

`telegram`, `sms`, `flash_call`, `max_bot` (и в будущем `voice`). Пользователь получает или считывает код, вводит его, а вы подтверждаете через `POST /v1/verify/check`.

→ [Подтверждение по коду](./code_verification.md)

:::tip Какой метод выбрать
Обратный flash-call — самый дешёвый и не требует ввода кода. SMS — самый дорогой, но работает на любом телефоне без мессенджеров и подходит как запасной канал.
:::
