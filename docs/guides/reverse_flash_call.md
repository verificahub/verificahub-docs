# Подтверждение номера обратным flash-call

Обратный flash-call (`reverse_flash_call`) — самый дешёвый способ подтвердить номер. Пользователь сам совершает короткий звонок на выданный номер, а Verificahub автоматически фиксирует его по определившемуся номеру. Вводить код вручную не нужно.

## Как это выглядит для пользователя

1. В вашем приложении пользователь нажимает «Подтвердить номер».
2. Вы показываете ему номер для звонка.
3. Пользователь звонит — звонок можно сбросить сразу, он бесплатный для пользователя.
4. Номер подтверждается автоматически за несколько секунд.

## Шаг 1. Инициировать проверку

```bash
curl -X POST https://api.verificahub.ru/v1/verify \
  -u api_key:api_secret \
  -H "Content-Type: application/json" \
  -d '{
    "phone_number": "+79991234567",
    "method": "reverse_flash_call",
    "expiry_seconds": 300
  }'
```

Ответ `201 Created`:

```json
{
  "request_id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "phone_number": "+79991234567",
  "method": "reverse_flash_call",
  "status": "sent",
  "cost": { "amount": 0.25, "currency": "RUB" },
  "expires_at": "2026-06-17T12:35:00Z",
  "number_to_call": "+79090000000",
  "code_length": 4
}
```

- `number_to_call` — номер, который нужно показать пользователю с подписью «Позвоните на этот номер».
- `request_id` — идентификатор сессии, по нему вы будете проверять статус.
- `expires_at` — до какого момента сессия активна.

## Шаг 2. Показать номер пользователю

Выведите `number_to_call` и попросите совершить звонок. Звонок короткий — пользователь может сбросить его, как только пошёл вызов.

## Шаг 3. Дождаться результата

Опрашивайте статус сессии, пока она не перейдёт в `verified` (или `expired`):

```bash
curl https://api.verificahub.ru/v1/verify/3fa85f64-5717-4562-b3fc-2c963f66afa6 \
  -u api_key:api_secret
```

```json
{
  "request_id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "phone_number": "+79991234567",
  "method": "reverse_flash_call",
  "status": "verified",
  "cost": { "amount": 0.25, "currency": "RUB" },
  "created_at": "2026-06-17T12:30:00Z",
  "verified_at": "2026-06-17T12:30:42Z",
  "expires_at": "2026-06-17T12:35:00Z"
}
```

Как только `status` равен `verified` — номер подтверждён, можно пускать пользователя дальше.

:::tip Совет
Опрашивайте статус раз в 1–2 секунды. Обычно подтверждение приходит в течение 10–30 секунд после звонка.
:::
