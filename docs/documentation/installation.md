Раздел описывает два случая: работу с размещённым экземпляром, для которой установка не требуется,
и самостоятельное развёртывание из архива с исходным текстом.

| Случай | Что требуется | Раздел |
| --- | --- | --- |
| Использование размещённого экземпляра | браузер и доступ в сеть | 1–3 |
| Самостоятельное развёртывание | Docker и Docker Compose | 4 |

---

## 1. Системные требования

Установка программного обеспечения на устройство заказчика не требуется.

| Параметр | Значение |
| --- | --- |
| Устройство | персональный компьютер, планшет или смартфон |
| Браузер | современный браузер: Яндекс Браузер (актуальная версия), Google Chrome 94+, Mozilla Firefox 93+, Safari 15.4+, Microsoft Edge 94+ |
| Разрешение экрана | от 320 пикселей по ширине |
| Соединение | доступ в сеть «Интернет», от 1 Мбит/с |
| Дополнительное программное обеспечение | не требуется |

Для обращения к программному интерфейсу достаточно любой среды, способной выполнить HTTPS-запрос.
Клиентские библиотеки не обязательны.

---

## 2. Получение доступа к размещённому экземпляру

Программное обеспечение предоставляется по модели SaaS и размещается на инфраструктуре
правообладателя на территории Российской Федерации. Распаковка дистрибутива и настройка на стороне
заказчика не выполняются.

Порядок получения доступа:

1. Зарегистрироваться по адресу https://app.verificahub.ru — указать адрес электронной почты,
   наименование и адрес сайта.
2. Подтвердить адрес электронной почты кодом из письма.
3. Получить ключ и секрет в разделе «Ключи» личного кабинета.
4. Пополнить баланс в разделе «Баланс».

После этого программный интерфейс доступен по адресу https://api.verificahub.ru.

---

## 3. Проверка доступности

```bash
curl -u '<ключ>:<секрет>' https://api.verificahub.ru/v1/prices
```

Ответ — перечень действующих способов подтверждения с ценами. Получение ответа означает, что
учётная запись активна и ключи действуют.

---

## 4. Самостоятельное развёртывание

По запросу правообладатель предоставляет архив с исходным текстом серверной части и личного
кабинета, разворачиваемый одной командой.

### 4.1. Требования к среде

| Компонент | Версия | Проверка |
| --- | --- | --- |
| Docker Engine | 24.0 и выше | `docker --version` |
| Docker Compose | v2 | `docker compose version` |

Платформа .NET, Node.js, PostgreSQL и Redis собираются и запускаются внутри контейнеров —
устанавливать их отдельно не нужно.

Свободные сетевые порты: `8080` (серверная часть), `3000` (личный кабинет).

### 4.2. Порядок развёртывания

1. Распаковать архив.
2. Перейти в каталог с распакованными файлами.
3. Выполнить `docker compose up --build`.

Первая сборка занимает от 5 до 15 минут. Схема базы данных создаётся автоматически при запуске —
отдельных команд миграции выполнять не нужно.

Готовность проверяется запросом:

```bash
curl http://localhost:8080/health
```

Ответ: `Healthy`.

### 4.3. Условия функционирования серверной части

| Параметр | Значение |
| --- | --- |
| Операционная система | семейство Linux |
| Оперативная память | от 2 ГБ |
| Дисковое пространство | от 10 ГБ |
| Доступ в сеть | требуется на время сборки — для загрузки базовых образов и зависимостей |

Для подтверждения номеров собственной инфраструктурой требуется парк абонентских устройств с
SIM-картами под управлением программного обеспечения устройства-шлюза, входящего в состав
платформы.
