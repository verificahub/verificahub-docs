# Публичная оферта

о заключении договора возмездного оказания услуг Verificahub

Дата вступления в силу: 15.06.2026

## 1. Общие положения

1.1. Настоящая Публичная оферта (далее — «Оферта») является официальным
предложением Исполнителя заключить договор возмездного оказания услуг на
условиях, изложенных ниже, в соответствии со статьёй 437 Гражданского кодекса
Российской Федерации.

1.2. Лицо, совершившее акцепт Оферты, становится Заказчиком и принимает её
условия в полном объёме.

## 2. Термины

2.1. «Исполнитель» — лицо, оказывающее услуги Verificahub.

2.2. «Заказчик» — юридическое или физическое лицо, совершившее акцепт Оферты.

2.3. «Сервис»/«Услуги» — предоставление доступа к платформе верификации
пользователей Verificahub через API на условиях выбранного тарифа.

2.4. «Сайт Исполнителя» — https://verificahub.ru.

## 3. Предмет договора

3.1. Исполнитель предоставляет Заказчику доступ к Сервису для подтверждения
номеров телефонов пользователей, а Заказчик оплачивает Услуги по факту их
оказания.

## 4. Стоимость и порядок расчётов

4.1. Оплата производится по модели pay-as-you-go: средства списываются за каждое
успешное подтверждение согласно действующим тарифам на Сайте Исполнителя.
