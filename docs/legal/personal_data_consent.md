# Согласие на обработку персональных данных

Дата вступления в силу: 15.06.2026

Настоящим, в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О
персональных данных», пользователь даёт согласие на обработку своих
персональных данных оператором — Verificahub (https://verificahub.ru).

## 1. Перечень данных

1.1. Контактные данные представителя (имя, телефон, email), а также номера
телефонов, передаваемые для верификации, и технические данные запросов.

## 2. Цели обработки

2.1. Оказание услуг верификации, биллинг, техническая поддержка, связь с
пользователем и обеспечение безопасности Сервиса.

## 3. Действия с данными

3.1. Сбор, запись, систематизация, хранение, уточнение, использование,
передача (предоставление, доступ), блокирование, удаление и уничтожение.

## 4. Срок и отзыв согласия

4.1. Согласие действует до достижения целей обработки или до его отзыва.

4.2. Согласие может быть отозвано направлением письменного уведомления на
hello@verificahub.ru. См. также [Политику конфиденциальности](./privacy_policy.md).
