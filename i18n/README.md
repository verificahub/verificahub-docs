# i18n — переводы контента

Переводы документации в формате, который ожидает Docusaurus. Русский (`ru`) —
локаль по умолчанию и живёт в `docs/`; переводы лежат здесь.

## Структура

```text
i18n/<locale>/docusaurus-plugin-content-docs/current/
  └─ <те же пути и имена файлов, что и в docs/>
```

- Пути и имена файлов **должны совпадать** с `docs/`, чтобы маршруты мапились
  один-к-одному (`/docs/...` ↔ `/<locale>/docs/...`).
- Переводим только `title`/`sidebar_label` во фронтматтере; `id`/`slug`
  оставляем как в оригинале.
- Примеры кода не переводим — только текст вокруг них.

## Что переведено (en)

`index`, `start`, `guides/*`, `faq`. **Юридические документы (`legal/`) намеренно
не переводятся** — для них Docusaurus автоматически показывает русскую версию
(fallback на локаль по умолчанию), и она остаётся юридически обязывающей.

## Что нужно в репозитории движка (`verificahub-docs-site`)

Этот репозиторий — только контент. Чтобы переводы заработали, в движке нужно:

1. В `docusaurus.config.js` включить локали:
   ```js
   i18n: { defaultLocale: 'ru', locales: ['ru', 'en'] }
   ```
2. Добавить переключатель локали в navbar (`type: 'localeDropdown'`).
3. На этапе сборки копировать `i18n/` из этого репозитория в корень сайта
   (рядом с `docs/`).
4. Строки интерфейса (navbar/footer) переводятся на стороне движка через
   `npm run write-translations --locale en` (файлы `code.json`), не здесь.
