# Project context — verificahub-docs

- Content repo for Verificahub documentation (Markdown), consumed by the
  `verificahub-docs-site` Docusaurus engine at build time.
- Default locale: `ru`. Production branch: `production`.
- Sections: `start/` (быстрый старт), `api/` (методы, reverse_flash_call),
  `legal/` (оферта, политика, условия — сокращённые черновики).
- `registry/links.json` is the external link map; keep it in sync with routes.
- Product: единая платформа верификации (обратный flash-call от 0,25 ₽),
  API base `https://api.verificahub.ru/v1`, site `https://verificahub.ru`.
